Blinkit Sales Insight Dashboard – Power BI

📊 Project Overview

This project analyzes Blinkit's sales data using Microsoft Power BI. The dashboard provides an interactive view of sales performance across outlet types, item categories, outlet sizes, location types, fat content, and establishment years.

🎯 Objectives

Analyze overall sales performance
Compare sales across different outlet types
Identify top-performing item categories
Analyze sales by outlet size and location
Understand sales trends by outlet establishment year
Build an interactive Power BI dashboard
